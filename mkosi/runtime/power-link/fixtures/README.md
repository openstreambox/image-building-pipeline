# Firmware wire fixtures

`firmware.txt` contains unchanged OSB1 lines captured from the protective
firmware host simulator (field flavour): basic, left-out-ina, stale restart
record, and storage hang/restart scenarios. Capture prints the fake serial
transmit buffer after each scenario, without changing firmware formatting.
The fixtures include complete status frames and boot diagnostics containing
`left-out=` and `restart-record=stale`. CRCs are the firmware output, not
regenerated by the reader tests. No physical device was involved.
