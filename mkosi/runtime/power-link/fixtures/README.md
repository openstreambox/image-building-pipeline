# Firmware wire fixtures

`firmware.txt` contains unchanged OSB1 lines captured from the protective
firmware host simulator (field flavour): basic, left-out-ina, stale restart
record, and storage hang/restart scenarios. Capture prints the fake serial
transmit buffer after each scenario, without changing firmware formatting.
The fixtures include complete status frames and boot diagnostics containing
`left-out=` and `restart-record=stale`. CRCs are the firmware output, not
regenerated by the reader tests. No physical device was involved.

`clock-offset.txt` is a finite field-flavour host simulation with 1200 ms
between setup and the first tick, then a synthetic hot reserve probe.
Only OSB1 output lines are retained (105 frames, including 27 events). The
reader test requires zero restarts and zero missed lines throughout. Event
uptime samples the emission clock; status uptime starts at the first tick.
The separate synthetic clock test also covers same-kind decreases after a
restart and verifies both clock histories are cleared. No firmware source or
hardware is needed to replay these fixtures.
